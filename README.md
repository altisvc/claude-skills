# Altis Claude Skills

Internal skills marketplace for Altis and Primary teams. Browse and install Claude Code skills at [skills.altis.vc](https://skills.altis.vc).

## Quick Start

```bash
/setup
```

## Structure

```
skills/       # Claude Code skills (.claude/skills/ format)
shell/        # Shell scripts and automations
setup/        # Onboarding skill
registry.json # Catalog metadata (the site reads this)
```

## Contributing

1. Go to [skills.altis.vc](https://skills.altis.vc)
2. Click "Submit New Skill"
3. Fill in the form — a PR will be created for review
